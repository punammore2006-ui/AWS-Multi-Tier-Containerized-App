# Multi-Tier Containerized Application

## Project Overview
This project demonstrates a multi-tier architecture using Docker containers.

## Technologies Used
- Python Flask
- MySQL
- Docker
- Docker Compose

## Architecture

Frontend
↓
Backend (Flask)
↓
MySQL Database

## Features
- Containerized Backend
- MySQL Database Integration
- Docker Compose Orchestration
- Multi-Tier Architecture
